# CLAUDE.md

This is the music website for Knaan Shabtay (knaanshabtay.com), a static site on GitHub Pages.

Before starting any task:

1. Add the private repo `knaansh/knaan-second-brain` to your session, pull the latest, and read its `SCHEMA.md` and `index.md`.
2. Read the wiki pages relevant to the task. For anything with public copy, that always includes `wiki/concepts/music-voice-and-bio.md`.
3. If the task produces a decision or something worth keeping, write it back to the wiki, update its `index.md`, add a `log.md` entry, and push.

Keep private notes out of this repo. It is public, and every file here is served on the live site.

Tag wiki log entries `(Claude)`.
